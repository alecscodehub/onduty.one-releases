# onduty.one downloads

onduty.one brings Grafana alerts to your desktop, with a service-status list, a tray/menu-bar quick view and local notification controls.

This public repository is the distribution location for desktop installers, checksums and release notes. The application source code is maintained privately and is not included here.

## Downloads

[Open the releases page](https://github.com/alecscodehub/onduty.one-releases/releases)

No installers have been published in this repository yet. Release publishing from the private build workflow still needs to be connected. Once published, the releases page will offer:

| Platform | Installer |
| --- | --- |
| macOS, Apple Silicon | `.dmg` |
| macOS, Intel | `.dmg` |
| Windows x64 | `.exe` and `.msi` |
| Debian / Ubuntu x64 | `.deb` |
| Linux x64 | `.AppImage` |

Choose the installer for your operating system and architecture. GitHub's automatically generated **Source code** archives contain only the files in this download repository; they are not application installers or the app's private source code.
